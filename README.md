# Ziggy-s-X-Giveaway-Picker-Chrome-dev-Extension
Most giveaway pickers for X that do not use the API, (which costs $) are not transparent about what they can and can't see. This one is. Use this on the X account that is hosting the giveaway that you want to pick the winner from. Everything is done manually by this chrome plugin to actually pick the winner. Many more options than most pickers.
